# 小样本文本分类与金融意图识别：近期进展及项目选题

调研日期：2026-10-26。重点覆盖 2024–2026 年，保留必要的 2023 年强基线。查阅论文正文、实验设置及部分作者仓库；未复现这些论文，不声称穷尽全部文献或确定当前统一 SOTA。本文不修改已有实验结论或开发任务完成状态。

## 1. 结论与上一轮建议的修正

这个方向仍有明确进展。之前只推荐 Label Tuning、AncSetFit、FastFit，偏重容易落地，不能代表近期研究全貌。

根据本次检索，我对近期路线的归纳是：研究不仅优化小样本分类器，还在优化监督信息从哪里来、类别边界如何表达、困难请求何时升级，以及知识如何压缩。以下路线并行存在，不能据此推断传统元学习已被替代。

- 直接适配与高效对比训练：降低训练成本，保留强而简单的基线。
- 标签语义与类别间差异：通过标签细化、标签引导距离等机制处理细粒度混淆。
- 数据生成与选择：用生成模型补充监督，并控制生成噪声和预算。
- 大小模型协作：以小模型处理容易样本，大模型处理部分困难输入。
- 压缩、主动学习和持续适配：分别降低部署成本、人工标注成本和新增类别成本。

对本项目最有研究价值的候选是“面向易混淆意图的定向监督”和“按不确定性选择二阶段判别”；它们是基于文献的选题建议，并非已经证明的原创算法。

## 2. 先明确我们研究的是哪一种小样本

当前项目为固定 77 类、每类 k 条训练样本的闭集分类，另有 1,003 条有标签验证数据。训练与测试包含相同类别，不是未见类别元学习，也未包含 OOS 识别。

| 设置 | 主要问题 | 与本项目关系 |
|---|---|---|
| 固定类别、少量标注 | 已知 77 类，减少每类训练样本 | 直接对应 |
| 未见类别 few-shot / episodic | 先从旧类别学习，再用少量新类别支持样本适配 | 需另设类别级划分 |
| LLM in-context learning | 不更新权重，以少量示例构造推理上下文 | 可作新对照，成本与训练模型不同 |
| 半监督 few-shot | 少量标签 + 更多未标注训练文本 | 必须单列额外数据预算 |
| 开放集／增量意图 | 拒识未知意图或持续加入新意图 | 属于未来扩展 |

不应把 10-way 5-shot accuracy、77-way 5-shot Macro-F1、使用生成数据的结果及使用额外无标签池的结果放在同一列直接排名。

## 3. 代表工作及其适用边界

### 3.1 FastFit：高效多类别训练的直接对照

2024 NAACL System Demonstrations。通过批内对比训练实现多类别小样本文本分类，作者提供开源实现。适合作为现有 SetFit/SupCon 之外的直接方法基线，不等于提出新的项目算法。论文速度优势仅适用于其模型、硬件及协议。[论文](https://aclanthology.org/2024.naacl-demo.18/)，[作者代码](https://github.com/IBM/fastfit)。

项目判断：适配成本相对可控，但仍要训练编码器；CPU 上应先小规模计时。效果对照尽量使用相同 backbone，若官方实现不支持则披露差异。

### 3.2 Clear Up Confusion：针对类别差异生成数据

COLING 2025。方法包含差异化生成指导、规则驱动精炼和迭代对比反馈。BANKING77 的 5-shot accuracy 为 84.41%，10-shot 为 89.67%；采用 Llama-3-8B-Instruct 生成数据，并为每类生成 100 条伪样本，分类器为 RoBERTa-base。[正文及表 2](https://aclanthology.org/2025.coling-main.151.pdf)。

项目判断：与我们的易混淆意图问题高度贴合，可借鉴的核心是“补类别区分证据”，而不是无差别改写句子。对照必须控制生成数量与成本；这些 accuracy 不能直接减去我们 MiniLM/BERT 的 Macro-F1 得出提升幅度。

### 3.3 Dynamic Label Name Refinement：按输入动态细化标签

ACL 2025 Short Papers，预印本首发于 2024 年。检索训练例子，结合输入动态细化意图名称，再进行 LLM 分类。BANKING77 为 10-shot；Llama3-8B 的 accuracy 从 85.88% 升到 87.95%。附录中一次性静态细化反而为 81.65%。[会议记录](https://aclanthology.org/2025.acl-short.3/)，[正文与附录](https://arxiv.org/html/2412.15603)。

项目判断：不能将动态重命名的收益视为“离线写更长类别描述必然有效”的证据。可探索离线边界说明以节省推理费用，但应与在线动态方案区分，并允许负结果。

### 3.4 FCSLM：小模型筛候选，大模型处理不确定输入

Findings of EMNLP 2025。使用小模型候选意图及不确定性，结合大模型进行精炼预测；还使用 LLM 辅助训练数据构建。论文采用 RoBERTa + Qwen2.5-72B，BANKING77 的 5/10-shot accuracy 分别为 87.66%/90.23%。[论文表 1 与实验设置](https://aclanthology.org/2025.findings-emnlp.749.pdf)，[作者代码](https://github.com/hustchenpeng/FCSLM)。

项目判断：适合研究准确率与调用成本的折中，原版不是全程低算力方法。若替换为轻量重排器，属于另一个需要验证的变体。候选召回不足时，后续判别无法恢复正确类别；必须测 top-k recall。

### 3.5 GLiClass / GLiNER2：可直接使用标签文本的小型通用模型

GLiClass 的 2025 预印本将标签纳入分类建模；GLiNER2 在 EMNLP 2025 System Demonstrations 中统一支持分类及信息抽取，并提供模型和工具。[GLiClass](https://arxiv.org/abs/2508.07662)，[GLiNER2](https://aclanthology.org/2025.emnlp-demos.10/)。

项目判断：可补零样本语义基线。使用现成权重的本地成本，与从头复现通用模型训练成本必须分开。引入权重前需核对具体版本、训练数据披露及基准重叠；不能因其声称零样本便推断从未接触相关数据。本文没有完成权重污染审计，也没有验证 CPU 延迟。

### 3.6 LDS：2026 年仍有标签引导的元学习进展

2026-02 首发 arXiv 预印本。Label-guided Distance Scaling 在训练和适配时引入标签语义。论文的 BANKING77 按类别划分为 30/15/32 个训练/验证/测试类别，评估 10-way、15-way 任务，并非固定 77-way。本文未确认会议录用。[正文 §5.1 和表 3](https://arxiv.org/html/2603.02267v1)。

项目判断：适合借鉴标签语义修正支持样本表示的机制，不能将论文结果直接填入我们现有主表。若要复现其新类别泛化问题，应新增类别级隔离实验。

### 3.7 Curate–Train–Refine：用大模型管理数据，小模型负责部署

2026-01 arXiv 预印本。以迭代生成、训练、诊断、补数据的闭环指导轻量分类器；正文使用 GPT-5 和 SetFit，验证集也由生成模型构造，实验覆盖四个分类基准，没有 BANKING77。[方法与表 1](https://arxiv.org/html/2601.16530v1)。

项目判断：值得借鉴离线数据策划思路，尚不能证明对我们的 77 类细粒度任务有效。表中存在闭环不如一次生成的设置，不宜照搬摘要的普遍优势表述。要另外检查真实分布验证、合成验证偏差、循环次数及生成预算。

### 3.8 几何筛选：2026 年新方法也会在 BANKING77 失败

2026-08 arXiv 预印本，通过嵌入距离筛选生成样本。论文整体报告优于 SMOTE，但在 BANKING77 的结果为相对对照 −0.99 个百分点，CLINC150 为 +0.01；研究使用 10/25/50-shot。[正文 §III-A、§V-C 与局限](https://arxiv.org/html/2608.13866v1)。

项目判断：这是反对直接照搬平均涨分的具体证据。可作为生成数据筛选对照，不是当前首推方案。该负结果也不能外推为所有几何筛选均无效。

### 3.9 压缩与主动选样：高效还可以指部署和标注效率

Minimizing PLM-Based Few-Shot Intent Detectors（2024）结合生成增强、蒸馏与词表裁剪，报告约 21 倍模型内存压缩；该数字不等于推理速度提升。[论文](https://arxiv.org/abs/2407.09943)，[代码](https://github.com/hdzhang-code/smallID/)。

Active Few-Shot Learning for Text Classification（NAACL 2025）研究从未标注池中选择更有效的支持样本，主要围绕 LLM few-shot 使用。[论文](https://aclanthology.org/2025.naacl-long.340/)。

项目判断：前者适合工程部署阶段，后者适合另设“固定总标注预算”实验。当前按真实标签每类抽 k 条是分层采样，不等于标注前就能知道各类分布的主动学习流程。

## 4. 阅读新论文时必须核对的账本

| 维度 | 必须记录 | 容易误读的地方 |
|---|---|---|
| 标注 | 训练标签、验证标签、描述编写和人工筛查 | 仅报 k-shot 忽略大验证集 |
| 数据 | 外部任务数据、未标注池、生成样本数 | 把额外监督当成纯算法改进 |
| 模型 | 编码器、教师模型、是否额外预训练 | 换强 backbone 却归因于损失 |
| 训练 | 总时间、教师生成、搜索、失败重试 | 只统计小分类头训练时间 |
| 推理 | 平均及尾延迟、调用比例、token、候选规模 | 参数少不等于端到端快 |
| 协议 | 固定类别/新类别、way、shot、指标、种子 | 将不同任务的最高分合并排名 |
| 泛化 | 数据重叠、近重复、支持集抽样波动 | 将单种子或重复确定性运行当稳定性 |

已有 DFT++ 工作还表明，充分利用直接微调、上下文增强和自蒸馏，可以挑战依赖额外持续预训练的方法。因此新方案必须对比认真调好的简单基线，而非异常或欠调的 BERT。[Findings of ACL 2023](https://aclanthology.org/2023.findings-acl.706/)。

## 5. 针对当前项目的推荐

以下是本次调研后的实验建议，不是对效果的承诺，也不构成已验证的文献空白。

| 项目目标 | 优先路线 | 原因 |
|---|---|---|
| 本地 CPU 快速推进 | 缓存 MiniLM 表示，比较逻辑回归、类别中心、标签向量适配 | 先测表示和类别语义的价值，减少编码器反复训练 |
| 加入近期直接方法 | FastFit | 任务直接、开源、能与已有方法形成效果和时间对照 |
| 增加有解释性的研究内容 | 定向差异化增强 | 与相近意图边界、现有混淆分析形成明确问题链路 |
| 增加系统与成本亮点 | 不确定性触发的候选重判 | 能分析调用预算、错误修复与过度改判 |
| 部署小模型 | 蒸馏与裁剪 | 待选中有效教师之后开展 |
| 研究新类别适配 | 标签引导原型 + 类别隔离协议 | 需要新增实验任务，不替代当前闭集结果 |

最值得作为主线的研究问题：在相同真实标签、生成数量及成本预算下，面向类别间差异的监督，是否比随机增强或普通同义改写更能减少细粒度意图混淆？

若要求完全不使用生成模型，则改成：在固定编码器下，类别语义和局部判别能否以很少训练开销改善相近意图？这条线资源友好，但不能仅凭组合组件宣称算法新颖。

## 6. 最小研究方案与停止条件

### 第一批：不引入生成成本

- 固定现有 MiniLM、划分及采样 seeds 42/43/44，先做 5-shot。
- 对照冻结表示的逻辑回归、类别中心、标签语义适配；有计算资源再补 FastFit。编码器编码时间与后续分类训练时间分别统计。
- 记录 Macro-F1、accuracy、逐类 F1、既有 29 对混淆、训练参数量、训练和推理耗时。此批仅筛选，不能以它证明通用 SOTA。

### 第二批：只验证一个近期机制

二选一，避免一次叠加所有组件：

A. 定向增强：无增强、随机增强、同数量普通改写、同数量类别差异增强；先不加额外筛选，隔离生成策略。生成数量和总 token/费用均报告；若无法同时匹配，另做预算曲线。人工审核次数计入监督成本。

B. 选择性二阶段：小模型单独、全部请求二阶段、验证集阈值选择的部分二阶段；固定二阶段模型，报告 top-k recall、调用比例、正确改判数、错误改判数及成本曲线。可选小型重排器，但它不同于原版大模型协作。

### 第三批：验证稳健性

- 若候选在三个支持集种子上方向一致且成本合理，扩大至更多支持集抽样和 10/20-shot；将训练随机性与支持集抽样随机性分开记录。
- 冻结所有选择后统一测试。当前测试结果已查看，新增研究如实披露，不描述成从未接触过测试集的确认性实验。
- 不将历史测试误判用于生成方向或描述改写；只能用训练证据和验证反馈，反复验证的轮数与预算预先限制。
- 若无稳定收益，保存负结果并停止该分支。已有 CE/SupCon/HN 正式受控实验仍需独立完成，不能被新增方向替代。

## 7. 还不能下的结论

本次未复现论文、未完成所有训练语料审计、未系统检索全部 2026 年会议论文，也没有证据证明某个方法必然超越本项目的 SetFit/BERT。近期方法的存在可以确认；在本项目协议下谁最好，仍需公平实测。
