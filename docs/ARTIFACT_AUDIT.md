## 数据划分

从官方数据按现有代码和 seed 42 重建：训练池 9,000、验证集 1,003、测试集 3,080。审计文件记录源文件 SHA-256、重建后的有序数据指纹，以及各设置、各种子的训练样本指纹。

归一化文本交集：train/validation 为 0；train/test 为 19；validation/test 为 6。这些是原始官方训练数据与测试数据之间已有的重复文本，不能宣称三部分完全无文本重叠。保留官方测试集以保持当前结果口径；未根据此次复核修改测试数据或重写历史分数。

## 无法补证的历史缺口

- 当前检出中 60 组均无 `predictions.csv`。这些文件被 Git 忽略，无法核对逐条文本、预测标签或 Top-k 分数；不能从混淆矩阵反推真实逐条预测。
- 未保存验证集逐条预测，因此只能检查验证指标的内部一致性，不能独立复算完整验证评估。
- 历史配置未保存训练数据指纹。当前采样可确定性重建，但不能证明历史环境使用的就是这些样本。
- 原运行在其他机器完成，配置中的模型路径为当时的绝对路径。当前已有本地模型，但没有历史权重哈希可据以证明权重相同。

上述事项作为证据局限保留，不伪造或补写历史元数据。新增受控实验将保存数据指纹、训练预算和验证/测试逐条预测，以改进可追溯性。
