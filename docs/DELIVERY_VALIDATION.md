## 已验证

完整测试：78 项通过。包含小型真实 BERT 的训练、保存、重载、预测与报告集成；指标篡改、模型损坏、缺失正式组、smoke 混入、运行环境变化均会被拒绝；失败目录可保留并重跑，完整组可跳过。

实际本地 bert-base-uncased 三组 CPU smoke 均完成，每组一次更新。使用 GPU v2 的 SDPA 与梯度检查点；CPU 精度按既有策略解析为 FP32。逐条预测、逐类指标、混淆矩阵、更新预算和最佳验证步数复核通过。本地验证产物已清理，不作为源码交付或提交到 Git。

源码通过 Python 编译检查与 Bash 语法检查。另在临时的独立源码目录验证数据准备和测试执行，其中 4 项因未附基础权重和历史矩阵而按既有条件跳过；开发工作区完整测试无跳过。WSL 安装组合根据 PyTorch/NVIDIA 官方文档选择；开发机运行环境与 WSL 指定版本不完全相同，尚未在 WSL 安装该组合。

## 目标机器结果（2026-10-27）

RTX 5060 Ti 16GB / WSL2，CUDA 13.0、torch 2.14.0、BF16、SDPA、梯度检查点。5-shot × CE / CE + SupCon / CE + SupCon + HN × seeds 42/43/44 共 9 组全部完成并通过复核：测试集 Macro-F1 分别为 0.6831 ± 0.0112、0.7013 ± 0.0050、0.7019 ± 0.0034。CE + SupCon 相对 CE 的配对差值为 +0.0182（3/3 为正）；HN 相对 SupCon 为 +0.0005（2/3 为正，seed 44 为负），不成立。训练加周期验证约 84 秒/组，测试吞吐约 3,445 条/秒，峰值 allocated 约 2.14 GiB。

产物在 `outputs/job_ready_gpu_v2_retry/`：协议与环境指纹、逐组配置、指标、训练历史、逐条预测、混淆矩阵，以及 `delivery/` 下的报告、效果/成本表、逐类变化、29 对混淆表和真实错误案例。文本产物随 Git 交付，模型权重（约 5 GB）只留在运行机器上。演示模型按平均验证表现选中 CE + SupCon、固定 seed42，记录在 `delivery/selected_model.json`；单条/批量推理入口已在开发机用 CPU smoke 验证。

结论只覆盖 5-shot、3 个种子、9 组，完整 36 组未运行；受控组与历史 60 组训练预算不同，数字不可逐行相减。详细数字见 [RESULTS.md](RESULTS.md) 第 6 节。

## BF16 并列预测修复

收到目标机器日志：9 组均训练 300 次更新，汇总在验证分数一致性检查处失败。复核发现导出使用非稳定 argsort、选模使用 argmax，并列最高分类分数时可能选中不同类别。已统一并列规则，增加保留原结果的 checkpoint 重导出工具；不训练、不改变模型选择规则、不放宽验证容差。

修复后 82 项测试通过，包括 77 类全部 2,926 种两类并列组合、推理与导出规则一致、小型真实 BERT 的已有权重恢复、备份、重复执行和不可复现时拒绝替换。目标 GPU 上的重导出结果即上文 9 组，全部通过验证分数一致性检查。
