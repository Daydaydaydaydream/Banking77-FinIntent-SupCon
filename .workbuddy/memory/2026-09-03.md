### 踩坑记录（重要，复现必读）
1. **setfit 与 transformers/sentence-transformers 版本冲突**：pip 默认装到 `transformers 5.16.1` + `sentence-transformers 6.0.1`，而 `setfit 1.1.3` 会 `from transformers.training_args import default_logdir`（4.x 才有）→ ImportError。解决：降级 `transformers==4.57.6` 且 `sentence-transformers==3.4.1`（ST 6.x 强制要求 transformers>=5，三者必须对齐）。
2. **setfit 1.1.3 API**：用 `from setfit import Trainer, SetFitModel, TrainingArguments`（`SetFitTrainer` 已弃用）；`SetFitModel.from_pretrained(backbone, use_differentiable_head=False)` 得到 logistic-regression head（经典 SetFit）。
3. **HuggingFace 下载**：`huggingface.co` 直连失败（SSL/EOF，走本地代理 127.0.0.1:64639 不通），`hf-mirror.com` 可达。运行前必须 `export HF_ENDPOINT=https://hf-mirror.com`。
4. **pandas 3.0 `groupby.apply` 默认 `include_groups=False`**：会丢掉分组列。少样本采样改用「整体 shuffle + `groupby(...).head(k)`」。
5. **transformers 4.57 `TrainingArguments`**：字段名是 `eval_strategy`（不是旧的 `evaluation_strategy`）。
6. **运行方式**：从 `src/` 目录用 `python -m <module>`（脚本直接 `python x.py` 会因 `config` 不在 path 而 ImportError）。
